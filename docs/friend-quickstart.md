# 给朋友的一分钟上手(发布包专用)

这是一个**浏览器在线音乐合奏**项目:服务器负责节拍对齐与事件转发,每个玩家在
自己浏览器里跟着引导弹奏,所有人听到同一首曲子。9 首内置曲目,支持键盘/鼠标/
MIDI 输入、双引导模式、五线谱、曲目录制与分享。

> 音色: 内置曲目使用**自托管真实采样音色**(随发布包分发,约 13MB)——所有玩家从同一服务器加载,
> 音色完全一致,不依赖外部 CDN 网络。

## 环境要求

- Node.js ≥ 18(建议 20/22)
- 无需其他全局依赖(npm 会自动装好 ws/tsx 等)

## 三步启动

```bash
tar xzf orchestra-<日期>.tar.gz
cd orchestra
npm ci          # 安装依赖(只需一次,约 30 秒)
npm start       # 启动: http://0.0.0.0:8080
```

看到 `orchestra server listening on ws://0.0.0.0:8080` 即成功。

## 开始合奏

1. 本机浏览器打开 **http://localhost:8080**
2. 首次访问会弹出新手教程(可关,之后可在页头「新手教程/演奏手册」重新打开)
3. 填昵称 → 点「创建房间」→ 得到 6 位房间码
4. **局域网内的朋友**浏览器打开 `http://<你的IP>:8080` → 填码点「加入房间」
   - 查 IP: `ipconfig`(Windows) / `ifconfig`(macOS) / `ip a`(Linux)

## 演奏速查

- **钢琴键位**: 白键 `A–K`、`Z–M`;黑键 `W–U`、`Q–6`(两个八度 C3–C5)
- **鼓声部**: 同一排键变鼓垫(`A`=底鼓 `S`=军鼓 `D`=踩镲 …)
- **MIDI 键盘**: 点「连接 MIDI 键盘」(需 Chrome/Edge)
- 选曲 → 武装声部 → 房主点「▶ 同步开始」→ 全员同拍起奏
- 引导模式可切:下落音符 / 乐器高亮(鼓垫)/ 谱面跟随;判定计分可开关

## 常见问题

| 现象 | 处理 |
|---|---|
| 打开 8080 被占用 | `PORT=8081 npm start`,访问 `http://localhost:8081` |
| 别人连不上 | 检查防火墙放行 8080;确认对方访问的是你机器的局域网 IP |
| 没声音 | 点一下页面任意按钮(浏览器要求用户手势后才出声);或用「Sound Test」验证 |
| 想上公网 | 见 `docs/deployment.md`(WSS 证书 / nginx 反代 / systemd) |

## 目录速览

```
shared/   协议与曲目数据契约(客户端/服务器共用)
server/   Node 服务器: 房间/节拍时钟/事件中继/曲目分享 API/静态托管
client/   前端: React + Web Audio + OSMD 谱面(生产构建在 client/dist)
docs/     验证报告与部署指南
```
